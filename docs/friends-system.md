# 好友系统（2026-10-31）

## 入口和页面

主界面的“密钥加入”功能卡替换为“好友列表”。同盟大厅原有密钥加入能力保留。

好友页左侧依次为好友列表、添加好友、好友申请、推荐好友。列表卡片使用已有名片头像及所选皮肤，展示姓名、段位和在线状态。进行中的对局展示玩法名、真人数量及人数规格，例如“水月联合探索（2/4）”。推荐只从在线且尚未成为好友的玩家中随机抽取；搜索按姓名匹配，精确匹配优先。

点击卡片复用排位大厅、段位规则、排位金字塔、近十场记录和对局详情，隐藏两个创建排位按钮。全服排行榜按公开档案 ID 标记正在查看的玩家。可观战玩法使用已有观战及跨服切换流程；水月等尚未开放外部观战的玩法不显示观战按钮。

房间未开始时，好友按钮作为工具栏的布局项加入，不固定覆盖其他控件。空位邀请直接打开好友菜单。菜单顶端有好友申请和好友列表，主体可纵向滚动。桌面宽 320 像素，窄屏宽 300 像素，头像 32 像素，姓名 12 像素，操作按钮最小高 28 像素。好友排位页退出后恢复此前的好友菜单及原房间。其他真人的卡面或姓名可打开“添加好友 / 查看玩家战绩”二级菜单，自己的名片编辑操作继续保留。

好友申请红点由未处理申请数量驱动，固定显示，与悬停状态无关；接受或忽略后同步消除。

主好友列表的每张卡片提供“删除好友”按钮。删除通过现有服务端操作同时解除双方关系，清理双方邀请并持久保存，随后同步更新好友列表；离线或操作进行中按钮禁用。房间内的紧凑好友菜单继续保留邀请和预约操作。

## 邀请和预约

只有未开始、有空位、非测试的多人房间可发邀请。服务端从邀请者所在房间提取模式、区域、房号和房间创建时间，不接受客户端提供房号。好友收到邀请后可确定或忽略；勾选忽略该玩家邀请后，服务端对该发送者屏蔽一小时，跨设备、切服和重连有效。勾选后确定当前邀请仍可正常处理，后续邀请被屏蔽。

好友正在对局时按钮显示“预约好友”。接受预约会保存预约，不退出当前对局；离开对局后如原房间仍可加入，再提示确定。普通未处理邀请有效期两分钟，已接受预约保留最长两小时。原房间开始、变满、关闭或好友已经加入时撤销邀请。跨服加入仍使用现有服务器目录及账户交接流程。

## 服务端保存和同步

好友关系、申请、屏蔽截止时间和邀请保存于档案权威服的 `friends.json`；默认位置与玩家档案文件同目录。每次修改原子落盘成功后才返回成功，好友关系同时写入双方。不将好友关系写进需要区域交接的个人排位档案，避免双方分别位于不同服务器时争夺档案写权限。

两服沿用现有签名并压缩的档案 RPC，每三秒上报经过登录租约验证的在线状态。好友状态只在内容变化时下发；未确认的区域响应会重发。状态带进程序号与版本，客户端拒绝旧版本倒灌，避免红点、申请和邀请回退。来源失联十秒或租约失效后不再显示在线。

外部只使用公开档案 ID，好友 API 不接收或返回账户 aid、认证票据、网络地址或隐藏分。好友详情和对局记录从已有档案存储读取。搜索、推荐、详情和历史读取沿用较重请求限流，申请、接受、忽略、列表刷新不会额外消耗该限流桶。
