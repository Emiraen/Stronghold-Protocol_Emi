## 1. 第一次游玩与完整流程

### 1.1 从哪里进入

在娱乐大厅选择“水月模拟／水月与深蓝之树”，先确定难度，再进入房间与开局选择。支持 **1—4 名真人**；一个人也能完成探索。模式内可以分路合作，等待时可以查看队友战况。

### 1.2 一局按什么顺序进行

1. 选择 N0—N18 中的一个难度。难度确定后，本局不能中途改动。
2. 全队选择一种**分队**，决定本局共同的基础加成。
3. 每人选择一种**个人策略**。同队成员不能重复选择同一个策略。
4. 每人选择一项**初始供给**：增加 2 希望、增加 5 源石锭，或取得“热水壶”（生命上限 +1、希望 +1）。
5. 每人选择自己的**初始招募组合**，获得对应招募券；大家都完成选择后继续。
6. 每人用券完成招募，安排自己的编队。
7. 在路线图选择下一节点；多人可以申请分路，分别探索。
8. 处理作战、事件、商店、休整、得偿所愿等节点。进入作战前先配置编队，再进入备战与自动战斗。
9. 战后领取奖励、处理招募和晋升，继续路线。每层末尾及 Boss 边界需要集合。
10. 根据探索中取得的道具和选择进入结局，完成最终战斗后结束本局。

### 1.3 三个容易混淆的选择

| 名称 | 决定什么 | 对谁生效 |
| --- | --- | --- |
| 分队 | 初始资源、职业优惠、部署容量等探索基础效果 | 全队使用同一分队；数值按效果发到个人或团队 |
| 策略 | 卫戍体系中的盟约、刷新、装备和战斗能力 | 由各玩家分别选择并持有；少数效果会影响同场或全队 |
| 招募组合 | 开局拿到哪些类型的招募券 | 各人独立选择并使用自己的券 |

初始供给的希望和源石锭发给选择者；热水壶属于团队收藏品，按团队持有规则获得一次，重复选择不会无限叠加同一件非叠加藏品。

### 1.4 新玩家先记住

- 招募与晋升主要使用**希望**；商店主要使用**源石锭**。
- **携带容量**与**同时上场人数**分开计算，增加携带不等于自动增加部署名额。
- 战斗是卫戍式自动作战，放置、朝向、技能与装备配置主要在战前完成。
- 每个玩家都有自己的生命、护盾、干员和装备；灯火、骰子、收藏品等是共同资源。
- 事件的费用、前置和可选状态会影响能否执行；无法支付的代价不会凭空豁免。

## 2. 资源与归属

### 2.1 哪些共用，哪些归自己

| 内容 | 归属 | 怎么使用 |
| --- | --- | --- |
| 目标生命、生命上限、护盾 | 个人 | 决定自己的生存；不会把所有人的生命合成一条 |
| 希望、希望上限 | 个人 | 招募、晋升及部分事件 |
| 源石锭 | 个人 | 商店、投资及部分事件 |
| 招募券、干员、装备 | 个人 | 各自领取、招募和配置 |
| 灯火 | 全队 | 影响层间检定、事件条件及结局选择 |
| 掷骰次数、骰子类型 | 全队 | 商店刷新、事件判定、重投和战斗骰子共同消耗 |
| 钥匙 | 全队 | 秘匣、银行提现、传送和特定事件 |
| 收藏品 | 全队 | 取得后按收藏品规则作用于探索或战斗 |
| 指挥等级与经验、携带容量基础值 | 全队 | 分路的战斗同样推动共同成长 |
| 结局进度、关键事件历史 | 全队 | 任一分路取得关键进展，会改变整队路线 |
| 投资余额、认知、生机细胞 | 角色档案 | 跨局保存；本局资源不能覆盖档案记录 |

“全队收藏品”不代表每条描述都无条件作用于每一个单位。职业、位置、血量、是否完美作战等限制，仍按该收藏品自己的效果判断。

### 2.2 无加成的开局基准

在不计分队、个人策略、认知和初始供给时，每人初始拥有 **4/4 目标生命、6 希望、6 源石锭、0 护盾**；初始携带容量为 **6**，团队钥匙为 **0**，团队掷骰次数为 **5**。

初始灯火：N0—N5 为 100，N6—N9 为 85，N10—N18 为 70。个人默认同时部署名额是 **8**；加成和减益另算，最终最高 **9**。

### 2.3 希望、资金与源石锭分开看

- **希望**是招募和晋升的主要支出。希望上限与剩余希望是两件事；明确写“消耗希望及等量上限”的事件会同时减少两者。
- **源石锭**是探索商店货币。商店消费源石锭，不计入绮良、潘格尼尼的希望消费累计。
- 策略或盟约给予的普通卫戍**资金奖励**，按 **5 资金 = 1 希望**累计换算，不足 5 的部分保留到之后，不会每个节点清零。
- 绮良、潘格尼尼等“累计花费资金”型策略，在水月中按**实际消耗 1 希望 = 3 资金进度**计算。这个 1:3 是消费触发的计数，不是把余额兑换成三倍，也不改变 5:1 的收入兑换。
- 免费招募实际消耗 0 希望，不会凭空给希望消费累计增加进度。

## 3. 难度、灯火与区域回响

### 3.1 N0—N18 的主要变化

难度效果逐档保留；区域成长率使用当前难度那一档，随进入普通区域次数复合增长。下面的“新增”指该档相对上一档增加的规则。

| 难度 | 新增规则 | 每区域敌方生命／攻击成长 |
| --- | --- | --- |
| N0 | 基础难度 | 0%／0% |
| N1 | 我方受到的元素损伤提高 15% | 1%／1% |
| N2 | 第三层初始随机获得一件遭诅古物 | 2%／2% |
| N3 | 敌方法术抗性 +10 | 3%／3% |
| N4 | 招募三星及以上干员希望消耗 +1 | 4%／4% |
| N5 | 领袖单位攻击、防御额外 +15% | 5%／5% |
| N6 | 初始灯火 -15 | 6%／6% |
| N7 | 敌人移动速度 +15% | 7%／7% |
| N8 | 我方受到的元素损伤再提高 15% | 8%／8% |
| N9 | 敌人攻击速度 +15 | 9%／9% |
| N10 | 初始灯火再 -15 | 10%／10% |
| N11 | 精英和领袖单位生命额外 +20% | 11%／11% |
| N12 | 敌方法术抗性再 +10 | 12%／12% |
| N13 | 我方受到的元素损伤再提高 15% | 13%／13% |
| N14 | 同时部署人数 -1 | 14%／14% |
| N15 | 精英和领袖攻击、防御、生命额外 +20% | 15%／15% |
| N16 | 获得养育者基因种，启用对应高难基因掉落 | 20%／20% |
| N17 | 组合排异反应取代基础排异反应 | 25%／20% |
| N18 | 精英和领袖登场后 20 秒内，物理／法术受伤 -50%，攻击 +30% | 30%／20% |

N1、N8、N13 的元素损伤增幅是逐次相乘；N3 与 N12 的法抗直接相加。N4 加的是招募成本，不是把所有晋升也加 1。职业优惠、分队折扣及免费候选再按各自规则参与价格计算。

### 3.2 灯火与层间检定

灯火范围为 0—100，越低越需要留意层间检定和排异反应。普通第二至第六层进入时会进行对应检定；特殊传送区域与普通区域按各自类型处理。

- 作战出现漏怪，团队灯火基础扣 5。
- 本场结算中有人个人生命低于自身上限一半，再基础扣 5。
- 同一场结算按团队条件处理一次，不按人数重复扣同一项。
- 收藏品、灯油、区域回响会调整损失或恢复；诅咒收藏品的固定战后扣灯火可能独立发生。
- 检定可能产生排异反应、启示或平静结果；排异反应作用于具体干员，不等于扣掉所有人的目标生命。

### 3.3 掷骰、重投与“每次消耗 1”

当界面提供可执行的重投时，**当前参与者可以直接重投，无须再申请队友批准，每次扣 1 次团队掷骰次数**。骰子库存不是永久固定为 1；不同玩家使用的是同一个团队余额。

重投仍要满足具体场景的规则：

- 层间较差检定的重投由“自我审视”认知开放，当前新局规则为整局最多一次，且原检定必须允许重投。
- “得偿所愿”初次掷出 1 点时，“鉴别能力”允许该节点一次付费重投，新结果即使还是 1 也不能再次重投。
- 商店掷骰刷新每次消耗 1 次；它与招募券的免费刷新不是同一种操作。
- 普通事件中的掷骰选项按选项内容消耗次数，不能把所有骰子功能视作无限重试。

### 3.4 区域回响怎么影响玩法

每个生成区域会有一种回响，进入区域时先看其效果；以下按当前八类实际规则列出。回响可以在不同区域重复出现。

| 回响类别 | 收益／便利 | 风险／限制 |
| --- | --- | --- |
| 探索 | 区域多两列节点 | 灯火损失加倍 |
| 争斗 | 我方及非 Boss 敌人攻击速度 +50 | 我方治疗与回复量降至 30% |
| 改造 | 每个非战斗节点给参与者 3 源石锭 | 离开本层会收回该层临时所得尚未花掉的部分；支出优先使用这部分 |
| 枯荣 | 作战源石锭奖励翻倍 | 每次进入战斗时，参与者各失去 1 生命，最低保留 1 |
| 给养 | 30% 概率额外获得招募券 | 敌人法抗 +15 |
| 众我 | 指挥经验 ×1.5 | 敌人防御 ×1.5 |
| 徒长 | 每场结算后参与者生命上限 +1 | 生命及护盾损失加倍 |
| 适应 | 本层第一次得偿所愿额外获得收藏品 | 地图只揭示当前可选下一节点 |

回响“适应”只显示下一节点时，是当前区域规则；它与正常情况下整张节点图消失不是一回事。

## 4. 分队

### 4.1 13 种基础分队

分队是全队共同选择。所有当前参与投票者选完后，多数决定；平票优先房主的选择。表中为基础效果，认知升级见下一节。

| 分队 | 基础效果 |
| --- | --- |
| 指挥分队 | 目标生命上限和当前生命 +2；每场战斗后额外恢复 1 目标生命 |
| 集群分队 | 可携带干员 +2；同时部署名额 +2，但当前模式最终部署名额最高为 9 |
| 后勤分队 | 初始源石锭 +20，初始希望 +2 |
| 矛头分队 | 开局当前目标生命变为 1；我方攻击、单位生命 +15% |
| 突击战术分队 | 四星及以上先锋／近卫，招募希望 -2、晋升希望 -1；提高随机直升概率 |
| 堡垒战术分队 | 四星及以上重装／辅助，招募希望 -2、晋升希望 -1；提高随机直升概率 |
| 远程战术分队 | 四星及以上医疗／狙击，招募希望 -2、晋升希望 -1；提高随机直升概率 |
| 破坏战术分队 | 四星及以上术师／特种，招募希望 -2、晋升希望 -1；提高随机直升概率 |
| 研究分队 | 初始护盾 +3；战斗指挥经验 +30% |
| 高规格分队 | 开局额外获得一张随机精锐招募券 |
| 心胜于物分队 | 战斗增加额外收藏品机会 |
| 物尽其用分队 | 每进入一个新层获得 1 次掷骰次数 |

原始资料中的分队解锁说明属于来源记录；本项目当前入口提供 13 张选择卡，不应拿资料里的累计条件解释为“卡片当前必定锁定”。

### 4.2 三种分队的认知升级

仍选原来的分队卡。新局科技树默认全开，三种可升级分队直接应用第三档的累计效果，不需要再找另一张卡。

| 分队 | 第一档 | 第二档 | 第三档 |
| --- | --- | --- | --- |
| 心胜于物 | 完成地区委托可额外选择一次奖励 | 额外收藏品池升级，合作概率由 25% 提至 40% | 初始获得“生还者合约” |
| 物尽其用 | 改用八面骰 | 新层掷骰次数合计增加 2 次 | 每个战场节点战斗骰使用总上限改为 15 次 |
| 以人为本 | 安全的角落可额外选择一次奖励 | 符合职业与星级范围的晋升希望再 -1 | 指挥等级上限由 10 提至 11 |

### 4.3 怎么选

初次熟悉路线，可以选指挥分队提高容错；想较早招到高星，可考虑后勤或以人为本；计划集中招募某两类职业，可以选对应战术分队。矛头分队开局生命很低，选择前要先确认全队能承担漏怪风险。

## 5. 个人策略完整指南

### 5.1 阅读策略前先统一概念

- **回合**：水月每完成一个节点推进一回合，事件、商店等非战斗节点也推进，不是只数打过几场。
- **主动刷新**：自己在招募券里点击刷新。刚拿到券、第一次打开、切换券、重连重新显示候选，都不算主动刷新。
- **特殊刷新**：策略改变该次手动刷新的候选；满足条件时，这张券的当前特殊候选页可以连续招募多名干员。每个栏位购买一次，仍支付实际希望费用。
- **调度中心等级**：仍是卫戍策略用于干员／装备抽取的阶段概念，与指挥等级不同。佩佩、凯瑟琳的升级触发已经专门适配为指挥等级每升一级触发。其他写有“不超过调度中心等级”的随机奖励仍按当前探索阶段控制，不等于任意六星。
- **等阶与星级**：策略里有“二阶、四阶、VI 阶”等卫戍单位或装备描述；招募费用表里的“一至六星”是招募星级，不能把装备等阶当希望价格。
- **精锐**：干员的晋升形态。同名普通干员可保留多份，第三份合成精锐；也有券、装备和效果直接晋升。
- **获得时效果**：干员取得时触发的特质或效果，不等于再次使用主动技能。
- 资金奖励统一按第 2.3 节换算为希望；源石锭始终独立。

固定回合发放的干员、装备和老鲤暂存收入，在对应回合的路线入口结算，不要求那个节点恰好是战斗。读取棋盘的策略仍在备战检查；“余”的第八回合检查若遇到非战斗节点，会保留到之后首次备战执行一次。

### 5.2 40 种策略的当前效果

| 策略／能力 | 当前效果 | 使用要点 |
| --- | --- | --- |
| 华法琳 · 重点监护 | 开战时，场上每种不同等阶各随机一名我方干员，其所属盟约层数 +2 | 阵容包含不同等阶，可扩大获得加层的覆盖 |
| 阿米娅 · 众志合一 | 激活盟约种类达到 3／4／5 种以上时，所有干员攻击、生命分别 +20%／30%／40% | 看的是已激活种类，不是仅拥有多少种标签 |

### 5.3 特殊刷新最容易误解的地方

以佩佩为例：升一级指挥等级 → 储备一次特殊刷新 → 打开一张仍有刷新次数的券 → **手动点击刷新** → 本次候选优先萨尔贡，并开启该候选页的多名招募。

购买第一名后，剩余候选保留，可以继续购买第二、第三名；每人按标价分别扣希望。特殊页的“多名”来自当前候选栏位，不是给所有后续招募券永久解锁无限招募。再次刷新会替换这一页；若没有再次触发特殊效果，就恢复普通券的招募规则。

当拥有随机免费栏位时，买其他付费候选不会让该免费栏位重抽或消失；买掉它后，这页不会自动再补一个免费名额。

## 6. 招募券、希望与干员养成

### 6.1 开局四种招募组合

各玩家可以独立选择，不要求和队友选同一种。

| 组合 | 开局三张券 |
| --- | --- |
| 先手必胜 | 先锋、狙击、特种 |
| 稳扎稳打 | 重装、术师、狙击 |
| 取长补短 | 近卫、辅助、医疗 |
| 随心所欲 | 三张随机职业券，其中随机一张替换为免费六星券 |

免费六星券每页提供 **2 名六星候选**，可免费刷新 **3 次**，成功招募的六星不消耗希望。它不保证出现某个指定干员，也不因名字“随机”就变为自选全部六星。

### 6.2 普通券、高级券和进阶券

- **普通职业券**：每种可用星级通常各显示 2 名候选；若该星级剩余合格干员不足两名，就显示实际可抽人数。对应职业的抽取权重为原权重的 2 倍，其他职业仍可能出现。
- **高级干员调度券**：在全体当前合格干员中选人，通常不限制职业；拥有它不代表无条件免费，具体看候选显示的希望费用。
- **进阶券**：针对已招募干员晋升；指定职业或星级的券保留自身限制，不会给未拥有干员凭空晋升。
- **临时招募／直升／特殊来源券**：保留来源规定的免费、星级和晋升效果。商店、事件、委托获得的券会先进入招募流程，处理后返回原节点。

### 6.3 基础希望价格

| 星级 | 招募 | 晋升 |
| --- | ---: | ---: |
| 一星 | 0 | 0；仅在存在合格晋升形态时适用 |
| 二星 | 0 | 0；仅在存在合格晋升形态时适用 |
| 三星 | 0 | 0；仅在存在合格晋升形态时适用 |
| 四星 | **1** | 1 |
| 五星 | 3 | 2 |
| 六星 | 6 | 3 |

这是没有难度、分队、收藏品、策略和免费效果时的基础价。N4 及以上，三星及以上招募 +1 希望。职业分队的优惠、以人为本、收藏品等会继续计算，价格最低为 0。请以当前候选卡的实际费用决定能否支付。

### 6.4 每券三次刷新与 25% 免费候选

普通券通常只能招募 **1 人**，每张券自带 **3 次免费主动刷新**，部分特质／盟约可再奖励次数。免费刷新是免刷新费用，不是把整页干员全部变为免费。

**每次真正生成候选页，有 25% 概率指定其中一个栏位为免费候选**，包括取得券后的首次出候选与主动刷新。它不是“每个干员各有 25% 免费”，也不是“每刷新四次保证一次”。

这个结果跟随当前候选页保存：关掉再打开、切换显示、重连、查看详情，都不会额外抽一次。基础已经免费的一至三星、免费六星券和其他免费效果，仍可正常存在；25% 指新增的随机免费栏位判定。

### 6.5 同名干员与晋升

1. 第一份普通干员进入持有列表。
2. 第二份普通干员是独立棋子，可以单独携带、装备和摆放。
3. 第三份凑齐时，三份合成一名精锐形态。

合成后保留主实例的身份与装备，被消耗副本的装备退回库存。通过高级券、进阶券、博士投影等直接晋升时，遵循对应道具规则。已经晋升或没有可晋升形态的干员，可能从后续合格招募池中排除；不是所有干员都能无限重复获取。

### 6.6 处理完券再继续

招募、跳过、刷新和切换券都要使用当前券的状态。处理完本批券后，确认完成以继续路线；多人还需等其他参与者完成。放弃券会放弃它剩余的招募机会，不会自动把该券兑换为希望。

## 7. 路线与各种节点

### 7.1 怎样看节点图

路线从左向右推进，只能选择当前节点连线能到达的下一节点，不能直接跨列或跳到任意支路。选择节点后按当前小队的投票和领队确认进入。作战节点会提供对应关卡信息，进入前先看名称和战场情报。

支路较多时，地图可以横向、纵向滚动。电脑端可用滚轮及拖动查看，手机端可滑动；收藏品栏也支持横向滑动。路线页底部收藏品区域列出已取得的团队藏品，点入可查看完整效果。

### 7.4 事件怎么选择

当前小队共同选择事件分支，代价涉及个人资源时，检查当前参与玩家是否满足条件；共用代价从团队资源扣除。不要只看自己余额，也要看队友是否不足。

后续页面可能要继续选具体干员、收藏品或任务，第一次点击“答应交换”“由干员运送”只是进入下一步，不意味着马上得到最终奖励。事件发放招募券后，先完成招募／晋升，再回原事件继续。

以下情况会合理限制选项：希望／源石锭／骰子／钥匙不足，生命上限将低于 1，没有合格目标，收藏品前置不足，灯火不达标，结局未解锁，或当前层数不允许。关键结局事件、地区委托按**整局唯一**记录，分路不会复制次数；后期事件也不会为了补选择提前到前期出现。

### 7.5 安全的角落

常见项目包括：生命上限 +3、进阶券、希望 +3、携带容量 +1、掷骰次数 +2、灯火 +15。每次只会提供其中一部分，不能假设所有六项都同时出现。

已选项目不重复使用；“以人为本”认知第一档可通过现有的再次利用选项额外选择一次。看到“生命上限”时，区分上限提升与单纯治疗；具体是否同步恢复当前生命，按该奖励实际结算。

### 7.6 得偿所愿

1. 选择想要的收藏品。
2. 首次掷骰**不消耗团队掷骰次数**。
3. 点数为 1：结果为随机替代收藏品；若已开放鉴别能力，可先选择接受或花 1 次次数重投。
4. 点数为 2—5：获得选中的收藏品。
5. 点数至少为 6：获得选中收藏品，并额外抽取一件。

重投每个愿望节点最多一次，采用新结果。额外愿望候选、区域首次愿望奖励和同一节点的骰子结果是不同机制，不能通过反复打开页面重复领取。

### 7.7 风雨际会与紧急运输

**风雨际会**使用允许献出的收藏品交换。低／中稀有度换中稀有度，高稀有度换高稀有度；被交出的物品会失去所有权，不能仍按它继续享受持续效果。不交换时可以选择恢复目标生命的分支。

**紧急运输**选择具体干员后，该实例在本层暂时离开编队可用范围；离层时返回，结算派遣收益／晋升等结果。派主力前先保证剩余阵容能打过本层。如果不愿意派人，可选后勤分支获得 3 希望。

### 7.8 商店、刷新与前瞻性投资

- 基础商店按当前货架生成支援道具、职业招募券及收藏品。基础职业券价格 4 源石锭，基础支援道具价格 8；收藏品按各自售价，折扣与特殊货架会改变最终价。
- 掷骰刷新消耗 1 次团队掷骰次数：1—4 点更换两件商品，至少 5 点刷新整个货架；至少 7 点可能进入高稀有度商品与折扣规则。
- 投资每次存入 **1 源石锭**；余额上限 **999**。记录存放在本人角色档案中，由服务端同步，跨局保留。
- 开放提现后，每次消耗 **1 把团队钥匙**，最多提取 **8 源石锭**，还要受实际余额限制。
- 投资解锁使用档案中的历史余额纪录，不是把每次存入流水简单加总当门槛；提现不会倒退已解锁档位。

| 投资纪录达到 | 开放内容 |
| ---: | --- |
| 25 | 余额提取 |
| 100 | 与坎诺特相关的商店战斗入口 |
| 200 | 一格额外商品 |
| 325 | 收藏品“审判庭之火”进入对应可获得范围 |
| 500 | 再加一格商品 |

额外货架可能伴随加价，看到新增栏位先看实际售价。商店战斗是实际作战，完成后还要处理商人离开／战利品状态；不是免费重复领取所有商品。

## 8. 多人分路、召回与观战

### 8.1 分路会分开什么

领队同意单独行动后，队伍可分成多个小队并行探索。每个小队分别走节点、处理事件、备战和战斗。个人资源仍归个人；灯火、骰子、钥匙、收藏品、指挥等级与结局历史继续全队共用。

分路不会把一件团队收藏品复制成多份，也不会给每个小队重置一套团队骰子。一个分路正在消费共用资源时，另一个分路可用余额会随服务端状态更新。

### 8.2 为什么会等待

各自完成小节点后可以继续处理本小队流程；到了层边界、Boss 集合点或接受召回的安全边界，会等待其余小队。此时可以观察队友进度，不能替队友完成其个人招募或私有装备选择。

进入节点前，确认本小队成员已投票、领队已确认、奖励已处理、招募已结束，且没有召回确认或层间检定悬而未决。“1/1 票”只表示路线票数，不代表所有后续步骤已经完成。

### 8.3 召回怎么生效

领队发起归队请求后，团队表决与被邀请者本人是否同意是两件事。不能仅凭多数票强制把别人从节点中拉走。

- **当前在路线页**：达到安全状态后显示是否归队。
- **正在小节点里**：先完成事件／战斗及其奖励、招募等后续，再显示归队弹窗。
- **本人同意**：在安全边界进行归队或等待既定集合，不必进入一个领队已经完成的节点重新表决。
- **本人拒绝**：不强行改变该玩家所在分路。

### 8.4 战场与观战

普通作战每人独立棋盘；Boss 可安排至多两名玩家同场。观战只是切换查看对象，不能替对方摆位，也不会把两个独立战场的干员混到一个本地棋盘。

个人生命归零后淘汰，转为只读观战，不再投票、准备或领取该局个人奖励；领队被淘汰后会移交。没有存活成员的小队不会继续占着集合条件。

### 8.5 联防是什么

普通独立作战之后，本小队可由一名完美作战队员处理联防漏怪。漏出的敌人保留原路线，联防时生命、攻击按原值的 75% 处理；没有被救下的部分，按原来源玩家结算目标伤害。

联防不会把队友漏过的全部伤害随意转给救援者。Boss 同场的漏怪按席位顺序轮流承担；直接扣目标生命的机制按其来源另外计算。

## 9. 编队、装备、备战与战斗

### 9.1 每场作战前的操作

在作战节点点击开始后，先进入本场编队配置。点击干员卡片和“快捷编队”进入的是同一个配置流程。选好要携带的干员、技能、模组和装备，再进入棋盘备战，放置单位、调整朝向，最后准备。多人场地要等该战场所需玩家准备完成。

已经准备后要修改配置，先取消准备。正在作战、被派遣离队或受特定效果锁定的干员，不能随时更改。配置的是本局招募得到的实例，不会把这次选择覆盖到账号原有的干员配置。

### 9.2 持有、携带、部署是三个数量

| 数量 | 限制什么 | 基础值与变化 |
| --- | --- | --- |
| 持有干员 | 本局已获得的干员列表 | 受招募、晋升合成、遣散、派遣等影响 |
| 携带容量 | 本场编队可以选入多少名干员 | 基础 6，指挥升级、分队、收藏品等可以增加 |
| 同时部署人数 | 当前棋盘上可同时存在多少名计数干员 | 每人基础 **8**，最终上限 **9**；难度与委托可能减少 |

例如携带 6 人、部署名额 8 时，只能部署带来的干员及符合规则的额外单位；不会凭空生成另外两人。携带 10 人、部署名额 8 时，可以轮换使用编队，但不能同时放下 10 名计数干员。召唤物、支援装置是否占名额，按各自单位规则判断。

集群分队、认知、收藏品等提供的部署增益最终仍受 9 人上限约束。N14 的 -1、穿越峡谷期间的 -2 等限制独立计算；“最多 9 人”不代表所有情况下都能放 9 人。

### 9.3 技能、模组、装备与遣散

- 技能只能选择该招募形态已开放的技能；晋升可能改变可用范围。
- 模组要求干员已经晋升，且对应训练形态达到开放模组的阶段；没有合格模组时可以选择不装备。
- 普通装备通常每名干员可带 **2 件**。在库存中选择装备后指定干员，或通过已有拖动方式穿戴；装满时按界面处理替换。
- 消耗型装备穿戴后可能立即生效并消失。合成按现有装备配方处理，已穿戴材料也可能被纳入合成。
- 每人每完成 **2 场作战**获得一次常规装备发放；同场联防不额外算一场。策略额外给的装备与这个周期分开。
- 三选一、二选一、寻呼模块等产生的奖励，通过“待领取”继续处理；奖励待选不代表已经自动装备。
- 遣散在允许的非战斗阶段进行，初次备战不提供任意遣散。通常返还 1 希望，装备回库存；巫恋等策略触发交换时，使用其替换规则。

看干员面板时，区分训练基础值、模组与装备带来的变化，以及开战后才出现的盟约、策略、收藏品增益。开战触发的效果不必在路线页预先表现为永久面板值。

### 9.4 地形、朝向和预置敌人

高台单位放在高台或允许所有类型的格子，地面单位放在地面或允许所有类型的格子；只有明确写明的特殊能力可以突破地形限制。部署朝向会旋转攻击范围，要根据范围格确定覆盖位置。

地图自带设施、不可部署地形和召唤物的主人／范围条件仍然有效。购买支援道具不会把整张地图改成可部署区。关卡开局已在场的怪物会在备战时显示，便于观察路线和摆位；备战期间不攻击，正式开战后才参与作战。

### 9.5 自动战斗、视角和交流

水月使用普通卫戍的备战与战斗表现：备战参考收起商店后的棋盘视角，开战后使用正常战斗 HUD 与摄像机，默认按 **二倍速**进行自动战斗。技能、再部署和策略效果仍按各自战斗规则运行。

战斗内可以查看单位详情、使用允许的战斗支援、通过聊天按钮交流和观察队友。探索商店、干员调配与基因使用不作为战斗中操作。战斗结束后会在棋盘保留到胜利／完美作战动画完成，再进入后续页面。

如果棋盘位置不适合设备，可以在设置调整横向偏移、纵向偏移和缩放；具体范围见第 13 章。

### 9.6 支援道具

取得支援道具后，后续每场战斗按该种类补充固定数量。当前使用最近取得的一种支援类型；重复购买不把同种单场数量无限叠加，也不同时携带所有旧种类。

| 支援类型 | 每场提供 |
| --- | --- |
| 支援补给站 | 1 个便携式补给站 |
| 支援地雷组 | 3 个干扰地雷 |
| 支援轰隆隆 | 2 个轰隆隆先生 |
| 支援起重机 | 2 个安全起重机 |
| 支援防暴桩 | 2 个防暴桩 |
| 支援急救包 | 3 个急救包 |

放置仍受格子类型、费用、剩余次数和冷却限制。用掉本场次数不会把获得该补给的收藏品销毁；下场重新获得规定补给。

### 9.7 战斗骰子

战斗骰子与探索检定共用团队掷骰余额。每次放置消耗 **3 部署费用 + 1 次掷骰次数**，正常每个战场节点最多一次；物尽其用第三档认知改为每战场节点总共 15 次，同场成员共用该额度。

| 点数 | 敌人受到的效果 | 额外效果 |
| --- | --- | --- |
| 1—3 | 攻击速度 -20，移动速度 -50% | 无再部署调整 |
| 4—6 | 攻击速度 -30，移动速度 -70% | 无再部署调整 |
| 7—9 | 攻击速度 -40，移动速度 -80% | 我方当前剩余再部署时间减半 |
| 10—12 | 攻击速度 -40，移动速度 -80% | 清除我方当前剩余再部署时间 |

实际能掷出的点数由当前骰子决定：六面骰不会掷出 7，八面骰最高档为 7—8，十二面骰才有 10—12。装置持续 15 秒，期间新进入的敌人也可首次获得对应持续减速；再部署调整只处理当前倒计时，不永久修改以后每次的基础再部署时间。

上一个骰子装置结束后才能继续投放。重连、回到备战或重新显示界面不会退还已花掉的团队次数，也不会刷新同节点的使用额度。

### 9.8 盟约的人数、档位与层数

盟约是干员之间的组合效果。普通盟约通常按场上**不同干员**计人数；同一个名字的普通与精锐一般只算一个成员，两份同名普通也不能直接凑成两名不同成员。人数达到门槛后激活对应档位，层数再影响该盟约写明的数值；有层数不代表人数不足时也能生效。

- 远见、奇迹、投资人把符合条件的整备区成员也计入，不只是场上。
- 绝技按场上精锐棋子数计算，所有干员的精锐形态都可参与。
- 调和激活后，已有真实场上成员的核心盟约人数 +1；不会凭空激活场上完全没有成员的所有核心盟约。
- 助力的高档人数还区分普通／精锐形态；独行则要求符合其单成员条件，增加第二种独行成员会使效果失效。
- 余的加层对无层数盟约不生效；当前无层数盟约包括调和、协防干员、独行、绝技。

同场两名玩家各自形成自己的盟约阵容，不能把队友的干员直接并入自己的计数。影响共同敌人的减益则可能使同场队友同时受益。全部 **23 种盟约**的人数档位、计数范围、效果与层数公式见配套查阅表。

## 10. 生命、护盾、战利品与指挥升级

### 10.1 目标生命和干员血量不是一回事

干员战斗生命是棋子的存活状态；玩家目标生命是探索的生存资源。单位被击倒不必然直接扣目标生命，敌人漏进目标点才按其漏怪伤害结算。Boss、事件或关卡也可能有独立的直接扣生命机制。

目标生命归个人，降至 0 后该玩家淘汰。同队其他人仍存活时可以继续探索；存活玩家全部失去后，本局结束。

### 10.2 护盾怎样抵消伤害

**玩家护盾先抵消漏怪伤害，余下部分再扣目标生命。** 例如当前 4 生命、2 护盾，发生 3 点漏怪伤害，结算为消耗 2 护盾、扣 1 生命，剩余 3 生命。

护盾不加入真实当前生命和生命上限，不把依赖“生命高于／低于某值”的收藏品判定抬高。事件或关卡明确造成的直接生命损失绕过这类漏怪护盾。HUD 的可承受缓冲可能同时展示生命与护盾，动画也会显示护盾吸收；不能把显示缓冲理解成藏品判定用的实际生命。

护盾抵消伤害不等于没有漏怪：要求完美作战、没有漏怪的委托或效果，仍看实际作战结果。桑葚等提供给战斗单位的一层护盾另算，不能拿来抵消玩家目标伤害。

### 10.3 每场战斗结算什么

战斗结算会处理漏怪与直接生命损失、护盾、灯火、指挥经验、源石锭、关卡设施掉落、干员／装备效果、地区委托、招募券和收藏品选择。不是所有收益都通过一个奖励卡片发放：经验、货币及升级通常直接到账，券和藏品可能需要选择。

下表每格为 **基础指挥经验 / 基础源石锭**，未计认知、分队、回响、藏品和特殊关卡覆盖值。

| 区域 | 普通作战 | 紧急作战 | 险路恶敌 |
| --- | ---: | ---: | ---: |
| 第一层 | 10 / 2 | 12 / 3 | — |
| 第二层 | 12 / 2 | 18 / 3 | — |
| 第三层 | 14 / 2 | 24 / 4 | 32 / 5 |
| 第四层 | 16 / 3 | 30 / 4 | — |
| 第五层 | 20 / 3 | 36 / 5 | 50 / 7 |
| 第六层 | 20 / 3 | 36 / 5 | 0 / 0（最终战基础表） |
| 绀碧摇篮 | 20 / 3 | 36 / 5 | 50 / 6 |

特殊事件战、训练类关卡和部分变体有自己的奖励值，不强行套表。场中被摧毁的普通、带刺和特殊钱箱分别可带来 2、4、10 源石锭；没有打掉的钱箱不按已取得处理。

### 10.4 招募、收藏品与额外掉落

- 常规非最终战的招募奖励，基础是一组两张职业券候选中选一张，不是两张都领取。收藏品候选组通常也是两件中选一件。来源效果可以增加奖励组或改变候选。
- 本联合探索当前的基础收藏品掉落机会：普通作战 15%，紧急作战与 Boss 作战在可掉落时为 100%；心胜于物额外池按档位提供 25% 或 40% 的独立额外机会。
- 开放漂流秘匣认知后，普通／紧急／Boss 作战的秘匣机会分别为 5%／15%／20%。
- N16 及以上还有按层、节点类型和唯一组规则产生的改良基因道具，不代表每场必掉。

这些概率是本项目联合探索当前使用的掉落规则，不应当当作官方未公开的服务端权重。收藏品是否合格，仍受已持有、解锁与剧情来源限制。

### 10.5 漂流秘匣怎么开

取得秘匣后，通过对应处理流程选择：

| 开法 | 代价 | 结果 |
| --- | --- | --- |
| 用钥匙开启 | 1 把团队钥匙 | 取得秘匣已生成的内容 |
| 掷骰开启 | 1 次团队掷骰次数 | 至少 5 点取得内容；较低点数改得 2 源石锭 |
| 用武器打碎 | 无钥匙／骰子支出 | 放弃里面的内容，不再获得该秘匣奖励 |

内容在生成时保存，切换开法、关闭重开或重连不重抽。若内容是临时招募券，完成招募后再回原流程。

### 10.6 指挥等级的逐级经验与奖励

指挥经验与等级全队共用，分路战斗也会推动升级。每跨过一级就逐级发放奖励并触发对应策略，不会因为一次跳两级就漏掉其中一次佩佩／凯瑟琳触发。

| 升到等级 | 从上一级再需经验 | 每名存活玩家希望增加 | 携带容量增加 | 每名存活玩家生命上限增加 |

| 2 | 10 | 4 | 0 | 0 |
| 3 | 24 | 4 | 0 | 1 |
| 4 | 36 | 5 | 0 | 0 |
| 5 | 40 | 6 | 0 | 0 |
| 6 | 55 | 6 | 1 | 1 |
| 7 | 65 | 6 | 0 | 0 |
| 8 | 70 | 7 | 0 | 0 |

生命上限增加不会自动等量治疗当前生命。携带容量增加也不会提高独立部署名额。研究分队、认知和经验回响等会提高战斗经验，按本场实际倍率结算。

### 10.7 最终战为何没有普通领奖页

通往后续区域的普通关底仍使用正常战后流程；**整局结局的最后一战**完成后，播放完成动画并直接进入终局结算，不再弹普通关底的奖励选择／招募界面。该战已经产生的经验、货币和其他自动结算不会因跳过选择界面而撤销；第六层最终战的基础经验与源石锭本来就是 0 / 0。

## 11. 结局路线与特殊区域

**本章包含结局触发条件。首次游玩希望保留探索感，可以先跳到第 12 章。**

### 11.1 四个结局的终点

| 结局 | 结束区域 | 最终关卡 | 主要前置 |
| --- | --- | --- | --- |
| 平凡即是喜乐 | 第五层 | 认知即重担 | 默认路线，没有完成其他结局的有效前置 |
| 静谧时代 | 第五层 | “命运的宠儿” | 获得海潮的气息，保护猎潮的骑士活到关底 |
| 息潮的代价 | 第六层 | 大群所向 | 主教的研究 → 深蓝之心 |
| 如星空般深蓝 | 第六层 | 人之光辉 | 深蓝回忆 → 升华事件中取得决心／观望／犹疑之一 |

第五层并非必然结束：满足第三、第四结局条件，会继续进入第六层。进入了正确路线，也必须真正通过对应最终关卡，才算完成该结局。

### 11.2 结局怎样解锁

初始开放第一结局。完成第一结局开放第二结局，完成第二结局开放第三结局。完成任一有效结局会记录第四结局解锁；但第四结局的“开端—深蓝回忆”选项还要求第三结局已开放，因此只完成一次第一结局并不能立即跳过全部前置走第四结局。

结局解锁属于角色档案；本局能否选择，还要满足开局所用的解锁状态、当前层数、已发生事件、灯火及收藏品条件。关键事件不会在所有层任意刷新。

### 11.3 第二结局：保护骑士

1. 第二结局已开放时，在第一至第三层遇到**狂徒妄念**。
2. 选择“愤怒”，支付 2 希望及等量希望上限，取得**海潮的气息**；或选择“呼号”，花 1 次掷骰次数，点数大于 1 时取得帮助。选择“沉默”得到的是另一分支收益，不会取得骑士前置。
3. 海潮的气息提供部署名额 +1，并使**猎潮的骑士**出现在战场。需要保护他，不让他在途中被击败。
4. 第二至第四层可能遇到**骑士仍在**。“反抗”消耗 2 目标生命，得到“荒诞命运”（10 源石锭、1 把钥匙）；“挣脱”得到**骑士骨血**。
5. 骑士保持存活到第五层，对应关底改为“命运的宠儿”。通过后完成静谧时代。

骑士途中被击败，会得到**退行的罗辛南特**，他不再作为友军出场，也不能仅凭背包里还显示海潮的气息就维持第二结局资格。**骑士骨血使猎潮的骑士防御力 -80%，也会影响此前友方形态**；不要只按关底减防收益理解这件道具。

### 11.4 第三结局：主教的研究与深蓝之心

1. 第三结局已开放时，在第一至第三层的**开端**选择“决定潜入深海”，取得**主教的研究**。
2. 主教的研究使每次战斗结束后灯火额外 -5，要提前规划灯火补充。
3. 第四或第五层进入**深蓝之心**事件。要取得核心藏品，选择“搜寻园林”，且选择时灯火必须至少为 **20**。
4. 得到**深蓝之心**：灯火 -50，并立即使一名随机干员产生排异反应。灯火最低为 0，不会变成负数。
5. 第五层关底之后前往第六层，通过“大群所向”完成息潮的代价。

实验室其他搜索会消耗 20 灯火换收益；如果先花到不足 20，就可能失去“搜寻园林”的可执行条件。获得主教的研究还不等于完成第三结局前置，必须继续取得深蓝之心。

第五层持有深蓝之心时，还可能遇到**赞歌**，取得“绝唱”，随机获得两个启示。它是路线中的额外帮助，不能替代深蓝之心。

### 11.5 第四结局：深蓝回忆与升华

1. 满足第三、第四结局解锁要求后，在第一至第三层**开端**选择“‘深蓝’？！”而非潜入深海，取得**深蓝回忆**。
2. 深蓝回忆立即扣除 100 灯火，并使一名随机干员产生排异反应。“主教的研究”和“深蓝回忆”是互斥起点，同一次探索不能两边都取。
3. 第二至第四层可能遇到**深蓝仪式**：“关闭危险流程”恢复 30 灯火；“不做任何改动”取得**深蓝之树**，使敌人攻击速度 +15，并按无目标生命损失的战斗条件恢复灯火。
4. 第四或第五层进入**升华**，依据当时灯火选择一种结果。
5. 取得决心、观望、犹疑之一后，前往第六层，通过“人之光辉”完成如星空般深蓝。

| 升华选择 | 灯火门槛 | 取得藏品与效果 |
| --- | ---: | --- |
| “我是水月，我会完成博士的请求” | 至少 90 | **决心**：我方干员阻挡 +2、防御与生命 +120%、法抗 +20 |
| “让时间来解答吧” | 至少 50 | **观望**：我方干员阻挡 +1 |
| “大群非我，我即大群” | 无额外灯火门槛 | **犹疑**：我方干员阻挡 -1，最低为 1 |

三个结果选其一。低灯火会限制可选项，但仍可通过犹疑完成这条结局路线。深蓝仪式是途中影响风险和灯火的分支，真正确定第四结局还要完成升华，不能只拿到深蓝回忆就直接当作路线已齐。

### 11.6 多人怎样共同改变结局

结局进度是全局共享：一个分路取得关键道具、完成关键选择或导致骑士死亡，会影响全队。请在进入结局事件前用聊天确认目标。

当前路线判定优先级为 **第四结局 → 第三结局 → 第二结局 → 第一结局**。第五层具体面对哪个 Boss 仍取决于骑士状态；若已满足第六层路线，通过第五层后还要继续，不会在那里提前判成第二结局通关。

狂徒妄念、骑士仍在、开端、深蓝之心、赞歌、深蓝仪式、升华等关键事件按整局唯一记录。多人分路不能各刷一遍来叠加剧情收益，后期节点也不能提前出现在前期。

### 11.7 绀碧摇篮与第一结局 Boss 的变化

开放传送认知后，误入奇境提供符合条件的支线路径，进入需要 1 把钥匙。绀碧摇篮按“愿望 → 作战 → 作战 → 特殊 Boss”推进，存在分支与关卡变体；完成后返回原路线，不直接作为四结局之一。

第一结局“认知即重担”的 Boss 第一阶段被击倒后，第二阶段按本项目当前规则**保持地面状态**。这是当前联合探索的战斗调整，规划阻挡与地面输出时可以据此安排。

## 12. 跨局成长与认知塑造

### 12.1 结束一局后留下什么

个人本局生命、希望、源石锭、招募干员、装备和收藏品用于这次探索，下一局不直接继承。角色档案保存投资记录、结局解锁、探索评分、认知与生机细胞等跨局数据。

失败探索也会根据已经完成的实际内容结算个人评分。多人同局的个人经历可以不同，分路、招募次数等会影响各人的记录。服务端按同一局、同一角色记录结算，重复打开结果不会再加一份。

### 12.2 认知怎样获得和生效

- 每累计 **200 探索评分**获得 1 点认知，未满 200 的余分跨局保留。
- 原始认知共 **58 个节点、112 点总成本**，原始完整进度对应 **22,400 评分**。
- 本项目新局科技树**默认全开**，新账号和已有角色均直接启用全部节点，无需累积分数或手动点选。
- 新局生成一份全开的全队共同快照，不再按房主档案限制认知；不会把各队友加成相加。角色档案的真实评分与生机细胞继续正常记录，不额外补发评分。
- 本局开始后，档案后来发生的成长不会中途再发一轮初始资源。分路和重连仍使用本局开局快照。

三种可升级分队的九档认知效果见第 4.2 节。完整 58 节点名称、成本、前置和原始描述另列于配套查阅表。

### 12.6 排异反应

排异反应附着于干员实例，会随该干员进入后续战斗。它不等于玩家目标生命直接受伤，也不把同名其他实例自动变成同一种状态。

| 基础反应 | 效果 | 强化版附加变化 |
| --- | --- | --- |
| 造血障碍 | 血量未满时持续流失生命 | 流失更快，生命越低攻击越高 |
| 专注失调 | 所有技能自动开启 | 未开技能时攻击逐渐上升、攻速逐渐下降，技能结束重置 |
| 神经退行 | 部署后冻结 15 秒，本次退场前只触发一次 | 冻结 30 秒，期间攻击、防御 +200% |
| 血肉畸变 | 生命、防御、攻击、部署费、再部署时间 -50% | 改为 -75%，初始技力 +80 |

N17 起出现六种两两组合：退行与失调、退行与障碍、退行与畸变、失调与障碍、失调与畸变、障碍与畸变。组合反应同时承担对应基础效果，不能只按名字中其中一项安排阵容。

### 12.7 改良基因、同化与进化

**改良基因**随机使一名受到排异反应的干员永久进化；**改良基因组**使所有合格的排异干员永久进化。库存属于全队，候选也从存活成员的合格干员中选取；没有目标时不消耗。使用要在作战与待处理层间检定结束后进行，不作为战斗中的即时按钮。

进化使排异反应失效，提供 **35% 庇护**，攻击无视目标 **35% 防御与法抗**。庇护按战斗本身的同类规则取有效值，不把每个来源都额外乘一次。

N16 的养育者基因种还会让带反应的原始宿主在作战中同化周围正常干员；完成两次有效同化后，宿主在本场临时进化。被同化者会在本场承受相应反应，但不会因此成为可不断向外传播的新原始宿主。这类战斗内同化不等于使用改良基因永久改写整支队伍。

启示按当前区域状态和来源应用；表中“下次一次”“获得时”按字面只结算对应次数，不能把所有收益当作每场自动重复领取。

## 13. 资源、设置、重连与常见问题

### 13.1 进入前要下载哪些资源

地图、怪物模型、战斗必需贴图、基础图标及音效属于必要资源。没有完整预载时，游戏仍会按需请求必要内容；预载能减少进入地图和首次遇见新单位时的等待。

背景音乐属于个性化资源，语音也有对应下载分类。只下载必要资源，不代表全部 BGM、皮肤、立绘和语音已经存到本机。想离线命中更多外观、音乐与语音，需在资源管理中下载相应分类，或导入版本匹配的完整资源包。

资源存在**当前浏览器、当前站点**的本地存储中。换浏览器、换站点地址、无痕窗口或清除站点数据，可能不能继续使用原缓存。导入完成后再关页面，避免导入事务被中断。

### 13.2 预载、继续下载与“只有一个请求”

在资源预载面板主动开始所需分类，关闭面板后已开始的任务会继续；需要停止时使用暂停。续传会携带一个已有进度文件名，从该文件开始重新传输，包括该文件本身，以覆盖最后一个可能未完成的条目。

检查已缓存资源主要看条目是否存在，不要求每次进游戏重新计算全部缓存的散列。新下载、解压、导入和保存仍须完成正常接收流程；“已存在”与“当前网络传输结束”不是同一件事。

一次持续下载请求可以包含多份资源，文件会依次解包写入。浏览器网络面板里只看到一个请求，不等于只在传一张图片；以实际字节进度、文件完成数量和错误提示判断是否在前进。各分类可分别启动，也可分别显示进度。

预载默认优先华南资源服；游戏连接首选华东，失败再尝试华南。资源服与当前对局服务器承担的角色不同，不必为了预载切换正在游玩的游戏服。

### 13.3 BGM、音效和模型没有显示时

| 现象 | 先做什么 |
| --- | --- |
| 图标、地图、模型缺失 | 查看必要资源的下载状态与具体失败路径；确认资源包和游戏版本匹配 |
| 立绘／皮肤缺失 | 下载或导入对应外观资源；已选皮肤需要它自己的头像、立绘和战斗资源 |
| BGM 不播放 | 确认已下载个性化音乐、音乐音量未静音，并在页面内进行一次点击以允许浏览器播放声音 |
| 没有语音 | 检查已下载语音分类及语言，并检查语音音量 |
| 下载提示失败 | 保留当前进度，使用继续预载；不要一开始就清空全部缓存 |
| 已预载但换地址又重新下载 | 确认是否换了浏览器或站点来源，本地缓存可能不共用 |

水月探索使用水月相关音乐，实际关卡也可有自己的 BGM。音效与 BGM 分属不同资源用途，有攻击音效不代表音乐包已经下载完成。

### 13.4 摄像机设置

| 设置 | 可调范围 | 默认值 |
| --- | --- | --- |
| 左右偏移 | -30% 至 +30% | 0 |
| 上下偏移 | -30% 至 +30% | 0 |
| 大小缩放 | 50% 至 200% | 100% |

正横向偏移让画面向右，正纵向偏移让画面向下；缩放大于 100% 会放大棋盘。偏移按当前视口比例计算，手机横屏和电脑宽屏的实际像素不同。找不到合适位置时先重置，再小幅调整；范围格和点击位置跟随同一设置。

手机建议横屏，路线支路、底部藏品和干员列表可在各自范围内滑动。进入干员编队配置后，使用该页面的返回流程回路线，不要把底部列表滑动误当作选择节点。

### 13.5 掉线和恢复

服务端保存探索状态；若对局仍存在，重新连接后使用当前服务端进度恢复，不会靠重开页面退还骰子、重抽招募页或重复结算投资。主动退出、对局终止与临时网络断开是不同操作。

能恢复到哪一步取决于服务端仍保有的对局记录。不要为了强制“刷新结果”反复关闭页面或清理存储，这不会把已经提交的选择撤销。

### 13.6 常见玩法疑问

| 问题 | 处理方式／规则 |
| --- | --- |
| 分队、策略选完为什么还没进下一步？ | 看当前所有参与者是否确认；后面还有个人初始供给和招募组合，不能只看自己的卡片已高亮 |
| 路线 1/1 票为何仍等待？ | 确认领队操作、招募、奖励、召回弹窗或层间检定是否处理完；到层边界还可能需要集合 |
| 有些事件按钮灰色？ | 先看代价、灯火、层数、前置、合格干员或藏品目标；满足条件仍无响应，应记录具体选项报告 |
| 得偿所愿没有重投？ | 需要鉴别能力、初次掷出 1、当前节点未重投且团队仍有骰子；不是所有点数都能重掷 |
| 拿到佩佩升级次数，候选没变化？ | 它储备的是下一次主动刷新机会，须在券里点击刷新才消耗并生效 |
| 高级券为什么还要希望？ | 高级券扩大选人范围，不自动等于免费券 |
| 两份同名是否能共存？ | 普通形态的前两份可独立存在；第三份参与合成精锐 |
| 携带增加了，为什么上不了更多？ | 携带与同时部署独立，部署默认 8、最终上限 9，还受本局减益影响 |
| 有护盾，生命类藏品为何没触发？ | 它读取真实生命，漏怪缓冲护盾不提高生命判定 |
| 过了第五层为什么还要继续？ | 第三、第四结局有第六层；绀碧摇篮也不是固定终局 |
| 战后为何没出现招募选择？ | 最终结局战直接终局结算；普通战斗则检查是否仍有奖励待处理 |
| 地图只显示前面一列？ | 先看本层是否有“适应”回响；正常整张地图消失则应记录现场 |

报告异常时，尽量提供：游戏服、对局／房间信息、单人或人数、当前区域与节点、所选策略、按钮文字、是否分路，以及错误截图。资源问题另附失败资源路径；不要公开账号凭据。

## 14. 常用规则速查

| 想查什么 | 当前规则 |
| --- | --- |
| 人数 | 1—4 名真人，支持单人 |
| 基础个人资源 | 4/4 生命、6 希望、6 源石锭、0 护盾 |
| 基础团队骰子 | 5 次，另加分队／认知等 |
| 部署名额 | 每人默认 8，最终最多 9；独立于携带容量 |
| 基础携带容量 | 6，可由升级、分队、藏品等增加 |
| 四／五／六星招募基础价 | 1／3／6 希望；N4 起三星以上招募另 +1 |
| 四／五／六星晋升基础价 | 1／2／3 希望，继续计算适用优惠 |
| 普通券 | 各可用星级通常两名候选；普通页招一名；每券通常三次免费刷新 |
| 随心所欲 | 三张随机职业券，其中随机一张免费六星券；两名六星候选、三次刷新 |
| 高级调度券 | 全部合格干员可选，不自动免希望 |
| 随机免费 | 每次生成候选页 25% 概率出现一个免费栏位；关闭重开不重抽 |
| 特殊刷新 | 手动点券内刷新才触发；当前特殊页可逐格购买多人 |
| 同名干员 | 两份普通可共存，第三份合成精锐 |
| 资金奖励 | 5 资金累计换 1 希望，余数保留 |
| 希望消费策略 | 实花 1 希望计 3 资金触发进度，源石锭另算 |
| 战斗速度 | 默认二倍速自动战斗 |
| 护盾 | 抵消漏怪，不增加真实生命，不替代直接伤害支付 |
| 战斗骰子 | 每次 3 部署费 +1 次团队骰子；基础每战场节点一次 |
| 投资／提现 | 每次存 1；提现用 1 钥匙、最多取 8；余额上限 999 |
| 关键事件 | 合理层数及前置内出现；改变结局的关键事件与地区委托全局唯一 |
| 指挥等级 | 基础上限 10；以人为本第三档认知可到 11 |
| 普通路线层数 | 五层；第三／四结局续到第六层；绀碧摇篮是额外支线 |
| 认知 | 新局默认启用全部 58 节点；个人评分与生机细胞独立记账 |
| 最终战后 | 完成动画后直接终局结算，不再走普通奖励选择 |
