虽然可以不下载资源直接游玩，但下载资源后游戏将会更流畅，并且可以使用皮肤、干员语音等附加资源。

1. 标题屏

打开页面后首先进入标题屏，需先输入代号：

  • 博士代号输入框：填写昵称（有长度上限），会自动过滤控制字符与不可见字符。
  • 开始游戏：代号有效后点击进入大厅；代号为空时会提示。
  • 服务器选择下拉框：在多个服务器（如华东 / 华南）之间切换，旁边显示服务器状态（空闲 / 一般 / 繁忙）与重试。
  • 语言切换：右上角可切换中 / 英文。
  • 标题屏下方还有一排入口：公告（含「今日不再弹出」勾选，未读有标记）、设置、玩法说明（书形图标）、本机统计、全屏。
  • 若你有一场未结束的同盟，模式按钮会被 【断线重连】 取代，点击直接回到原座位。

2. 大厅：选择模拟协议

大厅标题为「选择模拟协议」，分左右两栏。

2.1 左栏：模拟方式（01）

三张模式卡，点选其一：

  • 独立模拟（SOLO）：1 名博士，休整期与机变阶段不限时。
  • 同盟模拟（ALLIANCE）：1–4 名博士，可由 AI 队友补位，包含联防与最终攻势合并生命值。
  • 娱乐模式（ENTERTAINMENT）：多人同盟，最多 20 名博士，分组卡池与轮选、多轮联防，不计排位。选择后需再点「多人模式」并设置房间容量。

左栏下方还有：

  • 03 加入同盟：输入同盟密钥或粘贴邀请链接，点「加入同盟」；下方列出最近的同盟，可直接点选。
  • 观战大厅：观看进行中的对局，仅观看、不操作不结算。
  • 作战提示：每 5 秒轮播一条提示，可手动翻页。

2.2 右栏：模拟难度（02）

四张难度卡：标准 / 险境 / 绝境 / 终极，每张卡显示：

  • 编号（AC-1 ~ AC-4）、回合数、是否「+ 隐秘核心」、描述与效果词条；
  • 战场信息：标准为「战场固定」，更高难度为「战场随机（共 N 张）」。

2.3 右栏：排位与创建

  • 开启排位赛开关：勾选后进行排位；险境 / 绝境 / 终极可计排位，标准始终不计排位分、不计定级。
  • 「?」按钮：查看段位积分边界表。
  • 排行榜：查看全服排行榜（神话及以上）。
  • 底部大按钮：独立模式为「开始独立模拟」，同盟为「创建同盟」，娱乐为「创建娱乐多人同盟」。

2.4 大厅顶栏

返回标题、Ping（网络延迟）、设置、玩法说明、干员调配（带已调整数量角标）、本机统计、对局记录，以及右上角显示你本人代号与博士编号的个人卡片。

3. 排位赛机制

3.1 段位

  • 黑铁 / 青铜 / 白银 / 黄金 / 白金 / 钻石 / 超凡：各分 3 个小段，每小段 100 分，起点分别为 0 / 300 / 600 / 900 / 1200 / 1500 / 1800。
  • 神话：2100 分起，神话一 2100–2199、神话二 2200–2299、神话三 2300–2549。
  • 赋能战魂：2550 分及以上。
  • 神话及以上，徽章末尾显示 #全服排名。

3.2 定级赛

  • 共 3 场，只能使用险境 / 绝境 / 终极。
  • 单场得分 = 难度底分 + 18 × 存活回合 + 盟约层数分 + 8 × 协助（上限 10）+ 胜场加成；三场合计夹在 0–2050（最高定级为超凡三 50 分）。
  • 参考：全败且每把存活不超过 8 回合，险境约在黑铁~白银、绝境至多黄金一、终极至多黄金三。

3.3 常规局计分

  • 表现分：难度预算为险境 25 / 绝境 40 / 终极 50，按六项权重与达成比例计算：
    • 存活 35%、有效总伤害 32%、Boss 伤害 12%、盟约层数 8%、完美作战 8%、协助 5%。
  • 存活门槛：神话 / 赋能需个人存活 ≥ 11 回合，其余段位 ≥ 9 回合才计入表现。
  • 扣分：神话 / 赋能失败、个人死亡或未达存活门槛时扣分（原扣额按难度 ×1.1，下限 30）；积分低于 2100 的段位不扣分。
  • 跳段（统治级胜利）：绝境 / 终极胜利，且盟约层数 ≥ 200、协助 ≥ 3、个人有效伤害 ≥ 1500 万；连续 ≥ 2 次时该场额外 +50。
  • 人数补偿：按开局参赛人数，3 / 2 / 1 人胜局额外 +10 / 20 / 30；失败时补 7 / 14 / 21，用于抵扣剩余扣分。
  • 隐藏分（ELO）：按实际表现对难度基准的偏离更新，K = 32，定级赛期间加减更剧烈。

4. 房间等待室（同盟）

创建 / 加入同盟后进入房间，主体为座位卡片：

4.1 座位卡片

  • 空位：显示「等待博士加入」，房主可点 添加 AI 队友。
  • AI 队友：标注「AI 队友」，房主可点关闭图标移除；排位房间显示「人机 · 不参与排位」。
  • 真人：显示头像框、昵称、博士编号与状态（已就绪 / 准备中 / 待命中 / 连接中断）；房主座位带皇冠与「创建者」，房主可点关闭图标踢出其他真人。
  • 排位房间中，真人座位显示其段位徽章。

4.2 邀请与补齐

  • 邀请框：显示 4 位同盟密钥，可「复制密钥」或「复制链接」（?room=密钥）发给朋友。
  • 匹配补齐：房主开启后自动匹配真人补位，显示候选人数，可随时取消。
  • AI 补齐投票：发起投票，队员「赞成 / 反对」，达到人数即由 AI 补齐。
  • 匹配成功确认弹窗：所有真人需独立「确认参加」，并对难度投票（票多者胜，平票取最高难度）；拒绝、未确认超时或掉线均取消本次匹配。

4.3 开始与离开

  • 房主底部可选择难度（标准 / 险境 / 绝境 / 终极），并在所有真人就绪后点 开始模拟。
  • 非房主点 准备就绪，等待房主开始；全员就绪前可取消。
  • 左上角红色按钮离开同盟；房主离开时创建者身份将移交或同盟解散。

5. 确认本局信息（1/2）

进入对局前的确认页，分左右两栏：

  • 左栏：敌方领袖（剪影、名称、技能、最终攻势所在回合）、战场（固定 / 随机及当前名称）、特训敌人（按阵营列出图标与说明，无则提示）。
  • 右栏：核心盟约与附加盟约的圆盘列表——可用为亮起，禁用为灰色并带「阵容不完整」角标；下方列出本局禁用干员。
  • 底部：可点 干员调配 在此时修改本局配置；显示「已就绪 x/N」及人员标记，点 准备就绪。

6. 策略轮选（2/2）

  • 左侧：按随机轮选顺序排列座位，每行显示状态（等待 / 决策中 / 已选策略）。
  • 右侧：40 名策略头像网格与详情面板，显示每名策略的初始生命值 N、名称与效果；选中后点「确认选择」。
  • 规则：每人可跳过一次（排到最后）；超时自动选华法琳；头像上橙色角标表示用该策略通关 3 次。
  • 独立模拟此阶段不限时，可自由选择。

7. ★ 干员配置（干员调配）

从大厅 / 房间 / 确认页点「干员调配」打开全屏面板，顶部有三个标签页：干员调配 / 干员持有 / 自选编队。

★ 7.1 标签一：干员调配（选技能与模组）

  • 左侧：112 名干员列表，可按阶级 / 职业 / 盟约筛选、搜索，可勾「仅看已调整」；卡片显示当前携带技能（S1–S3），已调整的有标记。
  • 右侧（选中干员）：
    • 技能：在 S1–S3 间选择，每个技能显示「默认」、SP 回复方式、初始 / 消耗 SP、持续时间与描述。
    • 局内数值：可切换预览普通 / 精锐形态，显示属性、攻击范围、特性与天赋。
    • 精锐模组：仅精锐生效，可选「不装备 / X / Y」等，含属性加成、特性增强与天赋变化。
    • 单名「恢复默认」。
  • 顶部：导出 / 导入配置、全部恢复默认，显示「已调整 N / 总数」。

★ 7.2 标签二：干员持有（替补）

  • 列出本季 NORMAL 类棋子，按阶级分组；每张卡同时显示本人与官方指定的替补干员。
  • 点卡片在 持有 / 未持有 间切换；可勾「仅看未持有」。
  • 标记为未持有时，商店、整备区、作战区与结算都显示替补干员（模型、技能、天赋、攻击范围），但盟约、特质、阶级、价格与合成仍按原干员。
  • 预设（PRESET）干员无论是否持有都由本人上场，不在此列；「全部持有」可重置。

★ 7.3 标签三：自选编队（DIY）

  • 4 个槽位：五阶 ×2、六阶 ×2，槽位卡显示「选择干员」及「调度中心等级 5 / 6 起出现在商店」。
  • 点槽位打开选择器，可按 全部 / 原型 / 已持有 筛选并搜索：
    • 已持有 6★：可任选其技能与精锐模组；
    • 原型干员：技能与模组锁定（与补位时一致）；
    • 五阶另有 4★ 原型（先锋、特种除外），六阶为 6★ 原型。
  • 选好后在右侧确认技能 / 模组，点「确认」；可「更换」或「清空」。
  • 自选干员只出现在你自己的商店，调度中心达到该阶后才刷新，价格与同阶干员相同；盟约按干员实际阵营派生，没有特质。

8. 设置菜单

标题屏 / 大厅 / 房间均可打开「设置」：

  • 语言：切换界面语言。
  • 背景音乐、音效：滑条调节（0–100），拖动音效滑条会试听。
  • 干员语音：开关、语音音量、语音语言（日语 / 中文）。
  • 静音、显示伤害数字开关。
  • 画面质量：高 / 中 / 低（低端设备建议调低或关闭阴影）。
  • 快捷键：可逐项改键——刷新商店、冻结 / 解冻、升级调度中心、撤退、出售、准备 / 暂停；点按键后按下新键即可，冲突会交换，「恢复默认」可还原；Esc 固定不可改。
  • 问题反馈：复制诊断信息（本机生成、不上传、玩家名与房间号会替换），用于提交 issue。
  • 底部还有 资源预载、加群、玩法说明 与「完成」。

9. 本机统计与对局记录

点标题屏 / 大厅 / 房间的「本机统计」打开全屏面板，顶部有四个标签页：

  • 总览：总局数、胜场、胜率、到达隐秘核心次数、通关隐秘核心次数、最远回合、累计时长；并显示单人 / 同盟场数、按难度分类的局数与胜率表，以及获得的称号与次数。
  • 策略：按每名策略统计使用局数、通过局数、通过率，按使用次数排序。
  • 战斗累计：汇总击倒敌人、领袖伤害、造成伤害、盟约层数、晋升次数、配发装备、消耗资金、完美作战、刷新次数、未击倒、损失生命、成功协助等数据。
  • 对局记录：每条记录按时间倒序显示时间、难度、模式、使用策略、胜负结果、回合数，每次加载 50 条；点一行可回看该局结算，中途退出的对局只留记录。
  • 顶部可导出 / 导入（JSON，按记录合并）与清空；全部数据只保存在本机浏览器，不会上传服务器。

10. 对局内界面速查

  • 休整期：底部商店栏依次为调度中心等级卡（升级）、干员卡、装备卡、资金卡（含「✕ 收起」）；按钮为「冻结」「刷新」；右上显示「剩余可放置角色：N」。
  • 机变（选卡）：暗色遮罩，左上显示家族名（悬赏决策 / 道具补给 / 机密商店 / 战术决策），卡片 3×2 排列，点两次确认；同盟轮流各取 1 张。
  • 作战：中央显示击倒「n/m」，右上显示 DP；盟约栏可见、商店消失；独立可点「暂停」，同盟不可暂停。
  • 联防：橙色「联防阶段」横幅，盟约栏变暗提示「层数叠加已禁用」。
  • 最终攻势：两人共享战场，用 ‹ › 切换左半 / 全景 / 右半；120 秒后继续，150 秒后全队每秒扣 1 LP。

本指南依据项目客户端实际代码（public/js/screens、public/js/ui、shared/ranks.js 等）整理，具体按钮与界面以游戏内实际显示为准。

11. 舟铲铲之战 · 从第一回合到最终攻势

规则版本：2026年10月15日 · 包含银阶赠送品阶限制与基础连胜／连败收入。

舟铲铲之战是一场以阵容养成和金币规划为核心的合作守线挑战。你在备战时购买、部署干员和装备，作战时由阵容自动应敌；通过保留金币、升级调度中心、挑选馈赠，把阵容一路培养到第21回合的最终攻势。

11.1 怎样开一局

  1. 进入大厅，选择娱乐模式 → 舟铲铲之战，设置1–8人的房间人数和难度，再点「创建舟铲铲之战同盟」。
  2. 邀请朋友或添加AI队友；所有真人准备后，由房主开始。
  3. 查看本局战场与敌人信息，完成策略选择，再进入首轮备战。模式不计排位；每人的初始目标生命值在所选策略基础上额外增加10。

每4人一组共享干员池，不足4人的组按实际人数组成。干员候选范围与普通模式一致；同组玩家争抢同一干员会影响可抽数量。优先与队友错开核心干员，有利于各自成型。

11.2 一回合要做什么

回合开始与收入 → 特殊选择（如有）→ 备战 → 个人作战 → 联防（如触发）→ 结算。馈赠和征召发生在指定回合，不是每回合都有。

  1. 先检查生存：观察上一场哪里漏怪，补上阻挡、治疗或输出；检查干员朝向、攻击范围和可部署位置。
  2. 再决定用钱：优先买能立即补强、凑成合成或完善盟约的干员；需要更高阶候选时投资升级；刷新前先想清楚自己在找谁。
  3. 整理整备区：购买的干员先进入整备区，再部署到合法格子。把装备交给能发挥它的干员，清理临时溢出区后确认准备。
  4. 作战后复盘：无漏怪与漏怪会分别累计连胜、连败。联防能帮助处理漏出的敌人，但不会把个人的漏怪回合改算为连胜。

通常3个相同普通干员可合成1个精锐，部分干员存在自身例外；合成奖励另按游戏规则处理。相同普通装备通常2件合成，装备与部署限制以对应面板提示为准。不要只堆同一类输出而忽略阻挡和治疗。

11.3 金币：留钱、吃息与连续胜负奖励

舟铲铲未花完的金币会保留到后续回合。确认准备时无需为了避免清零而花光资金，也不会出现普通模式的剩余资金确认提示。

基础存款利息按上回合结余计算：每满10金币额外获得1金币，最高5金币。例如9金币为0利息、20金币为2利息、50金币及以上为5利息。利息在下一回合开始时与收入结算；馈赠带来的特殊收益另行计算。

4–5场+2
6场及以上+3

胜负切换就从1场重新累计。例如「胜、胜、胜、胜、负、负」对应的额外奖励依次为「0、1、1、2、0、1」；6连胜后的第7场若继续胜利，仍获得3金币，而不是一次性结算累计总额。

判定依据是本人个人作战：无漏怪且未判失败为胜，漏怪或未完成守线为负。奖励关同样参与累计；联防不会另算一场。奖励在本回合结算时记账，下一次备战开始时随收入到账。此奖励是模式基础规则，无需先选「战绩滚雪球」类馈赠。

运营建议：阵容能稳定守住时，尽量在10、20、30、40、50的利息档位留钱；漏怪严重时优先花钱保血。连败奖励只能补贴经济，不足以抵消被淘汰的损失。

商店免费刷新次数可累积到下一回合。本回合没有用完的次数不会清零；后续获得的免费次数会继续相加，刷新时先消耗免费次数，用尽后才扣金币。例如剩余2次、下回合再获得1次，就有3次免费刷新。这与馈赠选择卡每槽各1次的刷新机会不同。

11.4 升级：2金币买1经验

点击调度中心的经验购买按钮，每次花2金币获得1经验，达到本级门槛后升级。购买单价不变，当前已降低升级所需经验并向上取整。

11.5 关键回合速查

  • R4：第一次奖励关；R5：银阶馈赠。
  • R8：第二次奖励关；R10：先选金阶馈赠，再征召，最后进入备战。
  • R12：第三次奖励关；R15：彩阶馈赠。
  • R16：第四次奖励关；R17–20：补齐核心阵容，准备最终攻势。
  • R21：最终攻势，集中资源完成最后挑战。

11.6 独眼巨人的馈赠：35秒内三选一

第5、10、15回合依次提供银、金、彩三个品质。每位玩家看到自己的3个候选，每个槽位各有1次免费刷新机会；刷新只替换该槽位，选择后本轮不能再改。

选择阶段独立计时35秒，不扣减备战时长。全员完成可提前结束；到时仍未选的玩家，会从其当前有效候选中随机获得一项。AI也会随机选取。个人先选完仍需等其他玩家完成或计时结束，随后统一进入下一阶段。

银阶盟约馈赠直接赠送的干员限定为1–3阶。例如「军械补给」赠送的维多利亚干员最多三阶；其他七种盟约的银阶赠送同样受此限制。实际直接赠送数量为1名，相关说明已同步。这个上限针对馈赠本身的赠送，不改变商店、征召、合成奖励或彩阶馈赠的规则。

选择时先看具体馈赠名与效果，侧栏标题也使用具体馈赠名。优先考虑当前主力盟约、眼前的生存缺口和剩余成长空间：银阶用于过渡，金阶帮助完善阵容，彩阶结合最终攻势需求选择。不要为了尚未抽到的核心，放弃能立刻帮助当前阵容的选项。

11.7 奖励关：多击杀，多拿装备

R4、R8、R12、R16为奖励关，敌人是10只普通猎狗；奖励关没有联防，需依靠自己的阵容处理。

  • 击杀不足5只：不获得奖励装备。
  • 击杀5–9只：获得1件装备。
  • 全部10只击杀：获得2件装备。

奖励装备限定1–5阶，品阶越高掉落概率越低。即使拿到低阶装备，也可以用于过渡或合成；不要把奖励关当成必出高阶装备的保底。上场前检查是否留有漏怪通道，尽量争取全清。

11.8 第10回合征召：同时看干员与装备

R10金阶馈赠结束后进入征召。候选以干员＋装备捆绑展示，每个分组有自己的候选池；按生命值较低者优先的顺序轮流选，每人拿1项，已取走的候选会从池中移除。轮到自己时再确认，超时会自动选取。

选择时同时比较两部分价值：能补齐阵容的干员、能强化主力的装备，以及整备区是否有空间。可以提前想好第一和第二选择，避免理想候选被取走后临时犹豫。征召完成后仍有正常备战时间整理收获。

11.9 新手一局的决策顺序

前期（R1–5）：先做出能守线的前排、输出与治疗，优先购买可用干员。R4争取拿满装备，R5围绕已经成型的阵容选银阶馈赠。

中期（R6–12）：在守线稳定的前提下积累利息，规划升级与刷新预算。连续胜负奖励每回合最多3金币，不要把它当成无限收入。利用R10金阶馈赠和征召补足关键位置。

后期（R13–21）：逐步把存款转换成战力，完成关键合成、装备分配和站位。R15选能服务最终阵容的彩阶馈赠，R16后重点检查最终攻势所需的持续输出与生存能力。临近终局，金币的价值主要在于能否及时转化为有效补强。

11.10 常见疑问

  • 银阶馈赠会直接给四阶以上干员吗？不会，直接赠送上限三阶；后续合成触发的其他奖励按其各自规则处理。
  • 连胜被打断，再赢一场能续上吗？不能。胜负一变就重新累计，新一段第1场没有基础连续奖励。
  • 队友帮我清完漏怪，算个人胜利吗？个人连胜判定仍看自己的作战结果，联防不改写已经发生的漏怪。
  • 选馈赠太慢，会减少备战时间吗？不会。馈赠有独立35秒；超时随机选择，之后照常进入征召或备战。
  • 为什么我选完不能立刻买干员？还在等其他玩家或馈赠阶段结束。R10还要先完成征召。
  • 留着金币确认准备会丢钱吗？舟铲铲会保留金币，下一回合还可按存款获得基础利息。
