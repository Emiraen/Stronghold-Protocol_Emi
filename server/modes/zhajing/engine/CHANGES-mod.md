# 本包相对上游 0.3.1 的改动

## 玩法
· 炸惊模拟（独立 / 同盟）：专属棋库、惊变卡与惊变羁绊、敌方惊变
· 最多 100 座房间；自选编队（5/6 阶各 2 个名额）
· 新惊变「回归基本功」；共感羁绊补入「我从山中来」
· 出老千：凑齐后二极管只会翻倍；大乱斗/猫/神秘商店/支票的特化
· 助力：炸惊下改为「休整期结束 +10 层（3 名助力 +30）」
· 娜仁图亚（见者有份）：借出的装备按件叠加
· 至简 / 红豆：卫戍「购买价格为 1」生效
· 砾（炸惊）：被击倒时正确获得【不屈】层数
· 岳羽由加莉：卫戍特质的 S.E.E.S 层数不再受「每名敌人一次」限制
· 特效「袖章」：单独装备即视为 S.E.E.S 成员（同构标记正常）

## 修复
· Boss 关（最终攻势 / 隐秘核心）叠的层数能带进后续回合与结算
· 隐秘核心解锁判定改用并入后的层数
· 羁绊页「所属惊变」列出全部成员名；进度不再显示 0/N
· 盟约成员名单只列卡池中真实存在的干员
· 月光馆学园校服：去掉未实现的「只可与袖章一同装备」限制文案
· 炸惊整备阶段每回合 +50 秒

## 本包移除
· 服务器切换 / 跨服大厅（联邦对端）
